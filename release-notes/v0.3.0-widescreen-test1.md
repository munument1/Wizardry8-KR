# Wizardry 8 1.24 와이드 호환 한글패치 v0.3.0-test1

**별도 설치형 시험판입니다. 실제 게임 화면과 플레이 검증은 아직 필요합니다.**

## 설치 순서

1. 정품 GOG/Steam Wizardry 8 **1.24**를 준비합니다. 기존 한패 사용자라면 게임 파일 검사로 순정 `Wiz8.exe`를 복원합니다.
2. [원본 Widescreen 1.0.3](https://github.com/abr17/wiz8-widescreen/releases/tag/v1.0.3)을 설치합니다. 같은 릴리스의 hotfix1도 지원합니다.
3. 첨부한 ZIP을 별도 폴더에 풀고 `install.cmd`를 실행해 게임 폴더를 선택합니다.
4. 순정 **Wiz8.exe** 또는 Steam/GOG의 기존 실행 버튼으로 실행합니다.

**기존 Wiz8_124_Korean.exe와 Fan Patch 1.28은 지원하지 않습니다.**

## 변경 사항

- 원본 실행 파일을 바꾸지 않고 한글 문자 매핑 3,299슬롯을 실행 중 적용
- NPC 대사의 CP949 변환 및 버퍼 두 곳 수정
- 새 와이드 옵션·실험 기능 본문 16개 한국어화
- 한글 글꼴이 러시아어 글꼴로 오인되지 않도록 자동 감지 해제
- 지원 파일 SHA-256 확인, 기존 파일 백업 및 `uninstall.cmd` 복원 기능
- 기존 1.24 한패 v0.2.9-test2의 번역 데이터·13개 한글 글꼴 사용

## 배포 구성

원본 와이드 패치의 핵심 `wiz8hy.dll`, D3D11 드라이버, 와이드 이미지는 포함하지 않습니다.
사용자가 원본에서 별도 설치합니다. 이 패키지는 MIT 로더에 한글 호환 코드를 추가한
`version.dll`, 한글 데이터, 설치·제거 도구, 라이선스 고지와 소스를 포함합니다.
이미지에 직접 그려진 영문 버튼 및 일부 오류 메시지는 남아 있습니다.

## 검증과 제한

- 32비트 로더 빌드 및 원본 1.0.3/hotfix1 대상 정적 검사
- 컴파일된 x86 어댑터 모의 실행에서 문자 매핑·대화 버퍼·옵션 번역과 잘못된 수정 위치 거부 확인
- 모의 INI API를 사용하는 PowerShell 설치·제거 검사
- 이 릴리스의 GitHub Actions에서 Windows 런타임 및 설치·제거 검사 실행
- Windows 자동 검사는 게임 코드 실행·GUI·전체 플레이를 대체하지 않습니다.
- 설치기는 Windows용입니다. Linux/Steam Deck 설치·플레이는 검증하지 않았습니다.

원본 와이드 패치를 업데이트·제거하기 전 이 호환판을 먼저 제거하세요.
설치 전 세이브 백업을 권장합니다. 문제가 있으면 `wiz8kr.log`, `wiz8hy.log`,
`wiz8ws.log`, `wiz8wide.log`와 문제가 발생한 화면을 함께 제보해 주세요.
