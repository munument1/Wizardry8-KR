# v0.3.0-test1 로컬 검증 기록

검증일: 2026-11-24. 실제 게임의 GUI 및 플레이는 검증하지 않았습니다.

- llvm-mingw 20261117, i686 MSVCRT로 32비트 로더 빌드 완료.
- 원본 와이드 1.0.3과 hotfix1에서 대상 문자열 16개가 각각 1회 존재함을 확인.
- 번역에 사용하는 모든 문자가 기존 3,299슬롯 매핑과 13개 글꼴에 포함됨을 확인.
- 두 버전의 와이드 훅 목록과 한글 수정 주소가 겹치지 않음을 확인.
- 컴파일된 x86 어댑터를 Unicorn에서 실행: 3,299슬롯 테이블 할당 및 바이트 일치,
  CP949 로캘 요청, NPC 버퍼 두 곳 수정, 옵션 16개 번역을 검증.
- 두 버전 각각 수정 위치 불일치 및 문자열 누락 시 게임 메모리를 바꾸기 전에 중단하는 것을 확인.
- PowerShell 구문 검사 통과. Linux PowerShell에서 INI WinAPI만 모의 구현해 설치·검증·제거,
  잘못된 실행 파일/와이드 훅/로더/손상된 배포 파일 거부, 백업 보존, 기존 번역 복원,
  Wine Bink 프록시 교체·복원, 세이브 보존, 별도 INI 설정 보존을 검증.
- ZIP CRC, 배포 파일 SHA-256 목록 검사 통과. 게임 EXE, wiz8hy.dll, D3D11 DLL, 와이드 이미지 미포함.

## 검증의 한계

Unicorn의 Win32 API와 테스트용 할당·로캘 함수는 모의 구현입니다.
Linux PowerShell 테스트의 INI API도 모의 구현입니다. 실제 Windows의 CRT 변환·DLL 로딩·파일 API,
와이드 엔진과의 전체 초기화 순서 및 게임 화면을 대체하지 않습니다.
Windows에서 실제 CRT CP949 변환까지 확인하는 `tests/runtime.cpp`와 설치 테스트,
GitHub Actions 설정을 준비했습니다. 이 로컬 검증 환경에서는 Windows 테스트를 실행하지 못했으며,
릴리스 배포 과정의 Windows 검사 결과는 해당 GitHub Actions 실행 기록을 확인하세요.

인게임 최종 확인 후 정식 배포로 전환해야 합니다. 현재 파일은 시험판입니다.
