# Wizardry 8 1.24 와이드 호환 한글패치 v0.3.0-test1

**Windows용 시험판입니다. 실제 게임 화면과 플레이 검증은 아직 필요합니다.**

## 설치

1. 정품 GOG/Steam **1.24** 게임을 준비합니다. 기존 한패를 썼다면 게임 파일 검사로 순정 `Wiz8.exe`를 복원합니다.
2. [원본 와이드 패치 1.0.3](https://github.com/abr17/wiz8-widescreen/releases/tag/v1.0.3)을 설치합니다. 같은 릴리스의 hotfix1 적용본도 지원합니다.
3. 이 한글패치 ZIP을 별도 폴더에 풀고 `install.cmd`를 실행한 뒤 **게임 폴더**를 선택합니다.
4. **순정 `Wiz8.exe`** 또는 Steam/GOG의 기존 실행 버튼으로 시작합니다.

`Wiz8_124_Korean.exe`와 `Wiz8_v128.exe`로 실행하지 마세요. 기존 한패를 이 호환판 위에 다시 덮어쓰지 마세요.
게임 폴더에 수동으로 `payload`만 복사하면 설정과 백업 절차가 빠지므로 설치기를 사용하세요.
설치기 실행에는 Windows 기본 PowerShell 5.1이 필요하며 Python은 필요하지 않습니다.

## 제거와 업데이트

게임을 종료하고 `uninstall.cmd`에서 같은 게임 폴더를 선택합니다. 기존 파일과 러시아어 자동 감지 설정을 복원합니다.
설치 뒤 다른 패치가 변경한 파일은 자동으로 덮어쓰지 않고 제거를 중단합니다.
백업은 `Wizardry8_KR_Wide.backup`에 남습니다. 재설치하려면 제거 완료 후 그 폴더를 다른 곳에 보관하세요.
**원본 와이드 패치를 업데이트하거나 제거하기 전에 이 호환판부터 제거**하세요.

## 구성과 지원 범위

- 기존 1.24 한패 v0.2.9-test2의 번역 데이터와 13개 한글 글꼴을 사용합니다.
- 원본 실행 파일을 바꾸지 않고 실행 중 한글 문자 매핑 3,299슬롯을 적용합니다.
- NPC UTF-16 대사를 CP949로 변환하고 두 곳의 버퍼 크기를 보정합니다.
- 새 화면 설정과 실험 기능의 텍스트 16개를 한국어로 표시합니다.
- `[Text] Cyrillic=0`을 설정해 한글 글꼴을 러시아어 글꼴로 감지하지 않게 합니다.
- 와이드 핵심 `wiz8hy.dll`·훅 목록·D3D11 드라이버·와이드 이미지는 **이 ZIP에 포함되지 않습니다**. 사용자가 원본 패치에서 설치합니다.
- MIT 로더 `version.dll`에 한글 호환 코드를 추가했습니다. 원본 로더의 Wine/Bink 및 파일명 처리는 유지합니다.
- 현재 설치기는 Windows용입니다. Linux/Steam Deck에서의 설치와 플레이는 검증하지 않았습니다.
- 와이드 패치의 이미지에 직접 그려진 영문 버튼과 오류 메시지 일부는 그대로 남습니다. '실험 기능' 페이지의 본문과 설정 항목은 번역했습니다.
- Fan Patch **1.28은 지원하지 않습니다**. 알려지지 않은 실행 파일 및 와이드 DLL/훅 조합은 거부합니다.
- 세이브 파일은 설치기에서 변경하지 않습니다. 설치 전 별도 백업을 권장합니다.

## 확인할 화면

메인 메뉴의 와이드 버전 표기, 새 게임의 한글 UI, NPC 긴 대사와 토픽 더블클릭, 저널, 아이템 설명,
16:9/16:10 화면의 마우스 위치, 해상도 변경, 저장/불러오기를 확인해야 합니다.
문제 제보에는 `wiz8kr.log`, `wiz8hy.log`, `wiz8ws.log`, `wiz8wide.log`를 첨부하세요.

## 빌드

Python 3와 llvm-mingw i686 도구 모음을 사용합니다. 코드는 별도 브랜치에서 관리합니다.

```sh
python widescreen/tools/build.py --toolchain /path/to/llvm-mingw/bin
python widescreen/tools/package.py --korean-zip /path/to/Wizardry8_KoreanPatch_1.24_JournalMonoGalmuri11_v0.2.9-test2.zip
```

빌드는 고정된 upstream 커밋 `20d0faf87f037f0327baee254b020c060f0d5e2d`의 MIT 로더와 MinHook만 컴파일합니다.
렌더러 SDK 헤더는 인터페이스 선언에 사용하며, 역컴파일 소스나 게임 핵심 DLL은 빌드하지 않습니다.
